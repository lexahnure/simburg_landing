RSP Solution

The operator side of eSIM: SM-DP+, eIM, and Entitlement — secure profile generation, binding, and delivery for consumer and IoT devices.

Consumer eSIM (GSMA SGP.22)

Secure profile generation and binding. Features seamless integration with the operator's BSS (ES2+), LPA communication (ES9+), and end-to-end delivery to the eUICC (ES8+). Profile protection keys are securely managed within an HSM. Fully GSMA SAS-SM certified.

GSMA SGP.22 ES2+ ES9+ ES8+ SAS-SM

IoT Provisioning (SGP.31/SGP.32)

Advanced eIM capabilities for headless devices. Manage profile states — download, enable, disable, and delete — via IPA without requiring user interaction or QR code scanning, fully managed over ESipa.

GSMA SGP.31 GSMA SGP.32 ESipa

Device Entitlement (GSMA TS.43)

Delivered in collaboration with our strategic partners, this solution bridges operator subscription management with native, on-device activation for handsets, wearables, and tablets.

GSMA TS.43
